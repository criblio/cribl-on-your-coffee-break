# cribl-on-your-coffee-break
Welcome to the repository of files used in the "Cribl On Your Coffee Break" series! In a month of videos we explore the Cribl platform the way *normal* IT people do - completely at random, getting sucked down rabbit holes, and doing whatever strikes our fancy at that moment. 

To help you with that, and ensure you aren't wasting time, we've provided some simple scripts to generate data. Detailed instructions on each script appear below.
